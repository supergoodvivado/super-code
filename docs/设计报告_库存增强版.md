# 自动售货机增强功能设计报告

## 1. 设计目标

在原有商品选择、数量选择、付款、出货和显示功能上，增加商品库存、缺货检测和管理员维护模式，同时保留手动逐元找零。

## 2. 库存管理

系统使用 16 个 4 位库存寄存器，每种商品复位后初始库存为 5，最大库存为 15。订单确认时检查库存减去当前订单已占用数量，避免重复预留造成超卖。成功出货后按商品数量扣减库存；库存不足时维持当前选择状态并产生 `sold_out_pulse`。

## 3. 管理员模式

管理员入口为 `SW=1110` 并长按 KEY4 约 2 秒。管理员状态包括商品选择、库存查看和价格设置。KEY2 对当前商品增加一件库存，KEY3 进入价格设置，拨码值 0-15 作为新价格，KEY1 保存，KEY4 退出。普通复位组合 `SW=1111 + KEY4` 保留不变。

## 4. 手动找零

付款确认后正常出货；如果实付金额大于应付金额，系统进入找零状态，`change_due` 保存剩余金额。KEY3 每次产生一个 `return_coin_pulse` 并将找零金额减 1；KEY2 根据拨码选择退 5、10 或 20 元，且不会超过剩余金额。

## 5. 状态机

用户状态为 `IDLE`、商品选择、数量选择、订单确认、付款、出货和找零；管理员状态为 `ADMIN_SELECT`、`ADMIN_VIEW`、`ADMIN_PRICE`。状态寄存器扩展为 4 位，显示状态码 0-9。

## 6. 验证结果

`sim/tb_vending_machine_core.v` 覆盖了初始库存、手动找零、出货扣库存、管理员补货、价格修改和库存耗尽拒绝。Vivado 2026.1 行为仿真输出：

```text
PASS: inventory, admin and manual change simulation completed.
```

HX7A75C 目标器件为 `xc7a75tfgg484-2`，实现阶段 DRC 为 0，已生成可下载 bitstream。
