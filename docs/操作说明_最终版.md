# 自动售货机板上操作说明

> **金额上限补充：**付款阶段的“保留余额 + 本次已投金额”最大为 255 元。任何会使该总额超过 255 元的 KEY1 或 KEY2 投币均被拒收：金额不变，红色 LED 短暂闪烁两次。

> **2026-09-10 付款逻辑更新：**付款阶段的 KEY3 用于确认付款。KEY1、KEY2 只累计投币；金额达到或超过应付金额后，必须按 KEY3 才会出货。KEY3 确认时金额不足，红色 LED 短暂闪烁两次，状态保持付款。金额寄存器为 8 位、上限 255 元；金额超过 99 元时，数码管只显示个位和十位。

## 1. 开发板模式

- SW1-SW4：输入商品编号、数量编号或纸币编号。
- KEY1：开始选择、确认商品、投 1 元硬币；在找零/退款且余额不为 0 时开始新一轮商品选择。
- KEY2：确认订单、投入纸币。
- KEY3：逐级返回。选择第一个商品时与 KEY4 相同：有余额时进入退款，无余额时回待机；选择第二个商品时返回第一个商品的订单确认页；数量选择时返回商品选择；订单确认时返回最后一个商品的数量选择。付款、找零时每按一次退 1 元。
- KEY4：在商品选择、数量选择或订单确认页清空订单；有余额时进入退款状态，无余额时回待机。付款时取消退款；拨码为 `1111` 且按 KEY4 时复位系统。
- LED1：已有商品被选中。
- LED2：正在投币。
- LED3：正在出货。
- LED4：正在找零或退款。
- 蜂鸣器：按键短响，出货时持续响一小段时间。

开发板实测开关方向：

- SW1-SW4 向上为 0，向下为 1。
- DIG/LED 拨到数码管模式。
- BUZ/SW 拨到蜂鸣器模式。

## 2. 商品编号

商品编号由 SW1-SW4 的 4 位二进制决定，共 16 种商品：

- `0000` = A11
- `0001` = A12
- `0010` = A13
- `0011` = A14
- `0100` = A21
- 依次类推
- `1111` = A44

## 3. 数量编号

选数量时只看 SW1-SW2：

- `00` = 1 件
- `01` = 2 件
- `10` = 3 件
- `11` = 3 件

## 4. 操作流程

1. 初始状态显示 `00000000`。
2. 按 KEY1 进入商品选择状态。
3. 拨 SW1-SW4 选择商品，数码管只有第 2、3 位会变化。
4. 再按 KEY1 锁定商品，进入数量选择状态。
5. 拨 SW1-SW2 选择数量，数码管只有第 4 位会变化。
6. 再按 KEY1 确认该商品。
7. 如果需要第二种商品，重复第 2-6 步。
8. 按 KEY2 确认订单并进入投币状态。
9. 投币金额达到或超过总金额后，自动出货。
10. 如果有找零，可按 KEY3 每次退 1 元；也可直接按 KEY1 使用余额开始下一笔订单。

选择过程中可用 KEY3 修改上一项：在订单确认页按 KEY3 可重新选择最后一件商品的数量；在数量选择页按 KEY3 可重新选择商品；正在选择第二种商品时按 KEY3 回到第一种商品的确认页；正在选择第一种商品时，KEY3 与 KEY4 相同，有余额退款、无余额待机。

## 5. 显示格式

8 位数码管从左到右显示：

```text
状态 商品行 商品列 数量 总价十位 总价个位 已投/余额十位 已投/余额个位
```

示例：

- 初始：`00000000`
- 商品选择中，A13：`11300000`
- 数量选择中，A13 数量 2：`21320000`
- 订单确认，A13 数量 2，总价 12：`31321200`
- 订单确认，A13 数量 3，总价 18：`31331800`

## 6. 投币方式

- KEY1：投入 1 元硬币。
- KEY2：投入纸币，纸币金额由 SW1-SW2 决定：
  - `00` = 5 元
  - `01` = 10 元
  - `10` = 20 元
  - `11` = 50 元

投币期间可以按 KEY4 取消，已经投入的钱会进入手动退款状态，再按 KEY3 每次退 1 元。

## 7. 找零余额继续购物

找零或退款状态的最后两位是当前余额。余额不为 0 时按 KEY1，可以直接开始选择下一笔订单，商品选择、数量选择和订单确认时最后两位继续显示该余额。

确认新订单后，系统先用余额结算：余额不少于应付金额时直接扣款并出货；余额不足时进入投币状态，最后两位显示“原余额 + 本次投入金额”。足额后自动出货，剩余金额再次成为找零余额。
