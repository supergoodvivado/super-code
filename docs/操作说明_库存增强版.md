# 自动售货机增强版板上操作说明

## 一、普通用户模式

SW1-SW4 向上为 0，向下为 1。SW1-SW4 的 4 位值按行优先映射商品：`0000=A11`，`0001=A12`，依次到 `1111=A44`。

1. 上电后显示 `00000000`。
2. 按 KEY1，进入商品选择；拨码选择商品，再按 KEY1 锁定。
3. 进入数量选择；SW1-SW2：`00=1件`，`01=2件`，`10/11=3件`，按 KEY1 确认。
4. 可按 KEY1 再选第二种商品，最多两种；按 KEY2 确认订单。
5. 付款阶段 KEY1 投入 1 元，KEY2 按 SW1-SW2 投入纸币：`00=5`、`01=10`、`10=20`、`11=50`。
6. 金额足够后按 KEY3 确认付款。系统出货后进入找零状态：KEY3 每次退 1 元；KEY2 配合 SW1-SW2 退 5、10 或 20 元。

库存为每种商品初始 5 件。库存不足时商品不能加入订单，只有出货完成后才按购买数量扣减库存。

LED1 表示订单状态，也用于错误提醒。商品缺货、付款不足、金额超过上限或订单已包含两种商品后再次添加时，LED1 会闪烁两次并同步蜂鸣器提示。LED2 表示付款，LED3 表示出货，LED4 表示找零/退款；进入管理员模式后 LED4 常亮。


## 二、管理员模式

将 SW1-SW4 拨成 `1110`，长按 KEY4 约 2 秒。数码管第一位显示管理员状态码：

| 状态 | 操作 |
| --- | --- |
| `7` | 商品选择页，拨码选择商品，按 KEY1 查看 |
| `8` | 库存查看页，KEY2 补货 1 件，KEY3 进入改价 |
| `9` | 改价页，拨码 `0000`-`1111` 选择 0-15 元，按 KEY1 保存 |

管理员模式下按 KEY4 退出。库存上限为 15 件。普通复位仍是 SW=`1111` 时按 KEY4。

## 三、仿真与下载

在 Vivado Tcl Console 执行：

```tcl
source <工程文件夹>/scripts/run_sim.tcl
source <工程文件夹>/scripts/run_build.tcl
```

下载使用 `vivado_project_hx7a75c/vending_machine_hx7a75c.runs/impl_1/vending_machine_top.bit`。
