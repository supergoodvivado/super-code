# 自动售货机 Verilog 课程设计报告

> **金额上限补充：**付款总额达到 255 元后，任何会造成溢出的后续投币均被拒收；寄存器金额不变，并使用红色 LED 两次短闪提示。

> **2026-09-10 付款逻辑更新：**付款阶段的 KEY3 改为确认付款。KEY1、KEY2 只累计投币，足额后不再自动出货；须按 KEY3 确认。确认时金额不足则红色 LED 短暂闪烁两次并保持付款状态。金额由 8 位寄存器保存，上限 255 元；数码管在金额大于 99 元时只显示个位和十位。

## 1. 设计题目

本设计完成一个基于 FPGA 的自动售货机控制系统。系统通过拨码开关和按键完成商品选择、数量选择、订单确认、投币付款、出货以及找零/退款等功能，并通过 8 位数码管、LED 和蜂鸣器显示当前状态。

## 2. 硬件平台

- 开发板：HX7A75C
- FPGA：Xilinx Artix-7 XC7A75T FGG484-2
- 开发软件：Vivado 2026.1
- 输入资源：4 位拨码开关、4 个按键
- 输出资源：4 个 LED、8 位七段数码管、蜂鸣器

## 3. 功能要求

系统实现如下功能：

- 支持 16 种商品，编号为 A11-A44。
- 商品价格由商品编号决定。
- 每种商品可选择 1-3 件。
- 一次订单最多选择两种商品。
- 订单确认后显示总金额。
- 支持 1 元硬币和 5、10、20、50 元纸币。
- 投入金额达到或超过总金额后进入出货状态。
- 若存在多余金额，进入手动找零状态，每按一次找零键退 1 元。
- 找零余额可保留：在找零状态按 KEY1 开始新订单，系统优先用余额结算，不足部分再投币。
- 投币期间可取消订单，已投入金额进入手动退款流程。
- 初始状态显示 `00000000`，并通过状态机分阶段限制可修改的显示位。

## 4. 模块划分

### 4.1 顶层模块 `vending_machine_top`

顶层模块负责连接开发板外设，包括时钟、拨码开关、按键、LED、数码管和蜂鸣器。该模块实例化按键消抖模块、自动售货机核心控制模块和数码管扫描模块。

### 4.2 核心控制模块 `vending_machine_core`

该模块实现自动售货机的主要状态机、商品选择、数量选择、金额计算、投币、出货和找零逻辑。

主要状态包括：

- `ST_IDLE`：初始状态，显示 `00000000`
- `ST_SELECT_PRODUCT`：商品选择状态，只允许商品行列位变化
- `ST_SELECT_QTY`：数量选择状态，只允许数量位变化
- `ST_ORDER_READY`：订单已选择，等待确认或继续选择第二种商品
- `ST_PAY`：投币状态
- `ST_VEND`：出货状态
- `ST_CHANGE`：找零或退款状态

### 4.3 数码管扫描模块 `seven_segment_scan`

该模块将系统状态、商品编号、数量、总金额、已投金额或找零金额转换为 8 位七段数码管显示。开发板数码管实测为段选低有效、位选低有效。

### 4.4 按键处理模块 `button_conditioner`

该模块对机械按键进行同步、消抖和单脉冲处理，使每次按键只触发一次有效操作。

## 5. 操作与显示设计

8 位数码管从左到右显示：

```text
状态 商品行 商品列 数量 总价十位 总价个位 已投/找零十位 已投/找零个位
```

初始状态：

```text
00000000
```

按 KEY1 进入商品选择状态后：

```text
1 商品行 商品列 00000
```

例如选择商品 A13：

```text
11300000
```

再次按 KEY1 进入数量选择状态后：

```text
2 商品行 商品列 数量 0000
```

例如 A13 数量 2：

```text
21320000
```

第三次按 KEY1 确认商品后，进入订单等待状态，显示总金额。例如 A13 数量 2，总价 12：

```text
31321200
```

## 6. 按键和拨码定义

- SW1-SW4：商品编号或纸币编号，实测向上为 0，向下为 1。
- KEY1：开始选择、锁定商品、确认数量、投 1 元硬币；找零/退款且有余额时开始新订单。
- KEY2：确认订单、投入纸币。
- KEY3：逐级返回。选择第一个商品时与 KEY4 相同：有余额时进入退款，无余额时回待机；选择第二个商品时返回第一个商品的订单确认页；数量选择时返回商品选择；订单确认时返回最后一个商品的数量选择。付款、找零时每次退 1 元。
- KEY4：在商品选择、数量选择或订单确认状态清空订单；有余额时进入退款状态，无余额时返回待机。付款时取消并退款；拨码为 `1111` 且按 KEY4 时复位。

## 7. LED 和蜂鸣器

- LED1：已经选择至少一种商品。
- LED2：正在投币。
- LED3：正在出货。
- LED4：正在找零或退款。
- 蜂鸣器：按键时短响，出货时提示。

## 8. 仿真验证

仿真文件为 `sim/tb_vending_machine_core.v`。测试内容包括：

- 复位后进入初始状态。
- 按 KEY1 进入商品选择状态。
- 商品选择和数量选择分离，商品编号与数量不会同时变化。
- 选择商品后正确计算总金额。
- 投币金额不足时保持投币状态。
- 投币金额达到要求后进入出货状态。
- 多余金额进入找零状态。
- 验证找零余额开始新订单、余额直接扣款出货，以及余额不足时继续投币。
- 找零完成后返回初始状态。
- 验证 KEY3 从第一个商品选择、第二个商品选择、数量选择和订单确认页的逐级返回，以及修改最后一件商品数量后的总价更新。

仿真通过时输出：

```text
PASS: vending machine core simulation completed.
```
